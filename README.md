# 🏠 Kiray — Smart Rental Platform

Kiray is a modern web-based rental management platform that connects **property owners** and **tenants** in a seamless and efficient way.  
It provides dashboards for owners to manage listings and inquiries, and for tenants to explore and request properties.

---

## 🚀 Features

### 👤 Authentication
- Firebase Authentication (Login / Signup)
- Role-based access (Owner / Tenant)
- Secure session handling

### 🏡 Owner Dashboard
- Add new property listings
- Manage existing listings (edit/delete)
- View tenant inquiries
- Track earnings and analytics
- Profile management

### 🧑 Tenant Dashboard
- Browse available properties
- View property details
- Send inquiries to owners
- Save favorite listings

### 📊 Dashboard Features
- Real-time UI updates
- Responsive design (mobile + desktop)
- Sidebar navigation system
- Clean modern UI theme

---

## 🛠️ Tech Stack

- HTML5
- CSS3 (Custom UI Design)
- JavaScript (Vanilla JS)
- Firebase Authentication
- Firebase Firestore (Database)
- Firebase Hosting (optional)
